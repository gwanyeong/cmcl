# Logo candidates

The site logo is `images/logo.svg` (inlined into the header, so `currentColor`
follows the header text color). To switch, copy one of these files over
`images/logo.svg` and regenerate `images/icon.png` (512×512) from it.

- `bz-circles.svg` — hexagonal Brillouin zone filled with a slowly
  color-shifting energy landscape and circular Fermi contours lighting up in
  turn. Tried as the site logo, then rolled back.
- `bz-fermi-contours.svg` — hexagon as the Brillouin zone, Fermi-surface
  contours lighting up in turn, glowing Γ point, blinking K points.
  Shortlisted alternative.
- `template-flask.svg` — the original Lab Website Template logo (Greene Lab,
  BSD 3-Clause). Currently in use.
